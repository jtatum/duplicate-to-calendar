How It Works

🚀 Quick Start

  1. Select your destination calendar above and click "Save Settings"
  2. Go to Google Calendar
  3. Click on any event to open its details
  4. Look for the "Duplicate" button in the event popup
  5. Click "Duplicate" to copy the event to your chosen calendar

📋 What Gets Copied

The extension copies these event details:

  • Event title and description
  • Date and time (start/end)
  • Location information
  • For birthday events: adds yearly recurrence automatically

Note: Attendees, attachments, video links, and existing recurring rules are not copied.

🔐 Permissions

This extension requires access to your Google Calendar to:

  • Read your calendar list for destination selection
  • View event details from the source event
  • Create duplicate events in your chosen calendar

Your data stays between you and Google - this extension doesn't store or send your calendar information anywhere else.

👤 Account & Authentication

Important: This extension uses your Chrome profile's primary Google account for authentication.

  • The extension will access calendars from the Google account you're signed into Chrome with
  • If you use multiple Google accounts, the extension may not access the account you're viewing in Google Calendar
  • Google's account switcher in the web browser doesn't affect which account the extension uses

For multiple account users: Use different Chrome profiles for different Google accounts, or make sure you're signed into Chrome with the same account you want to duplicate events from.

❓ Troubleshooting & FAQ
Q: I don't see the Duplicate button

A: Make sure you're on calendar.google.com and try refreshing the page. The button appears when you click on an event to view its details.

Q: The button shows an error (❌)

A: This usually means the extension couldn't find the original event or lacks permission. Try logging out and back in using the button above.

Q: Can I duplicate recurring events?

A: Yes, but only the specific occurrence you clicked will be copied (without the recurring rule). Birthday events automatically get yearly recurrence added.

Q: The extension can't access my calendar

A: Click "Logout" above, then visit Google Calendar to re-authorize the extension with the necessary permissions.

Q: My events/calendars don't show up, but I'm signed into Google Calendar

A: This likely means you're using different Google accounts. The extension uses your Chrome profile's primary Google account, not the account you're currently viewing in Google Calendar. Solution: Either switch to the correct Chrome profile, or sign into Chrome with the same Google account you use for Calendar.

Q: How do I use this with multiple Google accounts?

A: The easiest solution is to create separate Chrome profiles for each Google account you want to use. Each Chrome profile can have its own extension settings and will use that profile's Google account for authentication.
